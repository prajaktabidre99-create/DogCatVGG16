# 🐶🐱 Dog and Cat Classification Using VGG16 Transfer Learning

## 📌 Project Overview

This project focuses on **Dog and Cat Image Classification using Transfer Learning with VGG16 and CNN**.

VGG16 is a pre-trained Convolutional Neural Network (CNN) model that uses previously learned image features to classify new images.

The model is adapted for binary image classification to distinguish between dog and cat images.

## 🎯 Objectives

- Classify images into Dog and Cat categories.
- Understand Transfer Learning in Deep Learning.
- Use the pre-trained VGG16 architecture.
- Perform image preprocessing.
- Train and evaluate the classification model.
- Predict whether an input image contains a dog or a cat.

## 🧠 Model Used: VGG16 Transfer Learning

**VGG16** is a pre-trained deep learning model commonly used for image classification.

In this project, transfer learning is used to reuse the features learned by VGG16 and adapt the model for dog and cat classification.
